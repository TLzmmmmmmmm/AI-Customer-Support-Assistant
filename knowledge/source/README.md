# Curated RAG Snapshot

This directory is the AI project's curated snapshot of authoritative public content from the Shengborun website.

The website remains authoritative. The maintainer who publishes or accepts a website knowledge change is responsible for updating the matching JSON here, rebuilding ../documents.jsonl, reviewing the resulting diff and counts, and running the Core tests.

The runtime build reads only this directory. It does not parse or synchronize the Astro repository automatically.

See docs/knowledge-schema-v1.md for schemas, inclusion rules, provenance, validation, and the update workflow.
